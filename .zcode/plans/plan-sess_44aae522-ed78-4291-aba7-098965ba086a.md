## 交互设计

**1. 触发按钮(label 行右侧,hover-reveal)**
- 「项目(N)」行改为 flex:左侧文字(现有样式不变),右侧 `IconButton`:`folder-add-left` 图标(与主页添加项目同款)、tooltip/aria 复用现成 key `home.project.add`(添加项目)
- hover-reveal:悬停 label 行(或键盘聚焦按钮)时出现,样式与组头 dots 菜单同款(`hover-reveal opacity-0 group-hover/label:opacity-100 focus-visible:opacity-100`)

**2. 弹层(Kobalte `Menu`,复用 new-session 项目选择器样式)**
- `modal={false}` `gutter={6}`,内容宽 243px,`Menu.Content` 内放滚动列表 + 分隔线 + 固定动作行(选择器已有此结构)
- 滚动区 `max-h-[224px] overflow-y-auto`:列出各 server 的 `ctx.projects.list()`,**排除**已出现在分组列表中的项目(按 `projectGroupKey(server, worktree)` 匹配);单 server 平铺,多 server 按服务器分组小标题(同选择器做法)
- 每行复用主页行样式:`h-7 rounded-[6px] px-1.5` + `ProjectAvatar`(16px)+ `displayName(project)` 单行截断;`Menu.Item closeOnSelect` → 点击即关弹层
- 列表为空时不渲染行(只剩「打开文件夹」)
- 底部:`h-px bg-v2-border-border-muted` 分隔线 + 固定「打开文件夹」行(`folder-add-left` 小图标)

**3. 点击现有项目 → 加载其全部会话**
```
ctx.projects.open(worktree)
remote = await ctx.sdk.api.session.list({ parentID: null, order: "desc", limit: … })  // 主页索引同款
remote.forEach(s => ctx.data.session.remember(s))
sessions = ctx.data.session.list() 过滤:根会话(!parentID)、未归档,
           且 [worktree, ...sandboxes] 的 pathKey 命中 location.directory,或 projectID === project.id
sessions.forEach(s => tabs.addSessionTab({ server, sessionId: s.id }))   // 幂等,tabKey 去重
```
- 分组内按 `time.updated` 最近优先排序;**不导航、不改变当前选中 tab**(后台加载)
- 索引加载实现时核对 `@/home/sessions/index` 的导出签名,若不契合则内联一次 `session.list`

**4. 点击「打开文件夹」→ 复用主页添加项目逻辑**
```
pickDirectory({ server: 第一个server(同主页 servers[0] 惯例), title: language.t("command.project.open"),
  multiple: false,
  onSelect: result => {
    const [directory] = homeProjectDirectories(result)
    if (!directory) return
    addProjects(ctx, [directory])          // @/home/projects/add —— 去重/探测/open/touch 全复用
    void tabs.newDraft({ server, directory })  // 分组列表新增 组 + 新会话 tab
  }})
```

## 默认决策(请确认)

1. **多 server**:「打开文件夹」添加到第一个 server(与主页面板头按钮 `servers[0]` 惯例一致);项目列表按 server 分组展示。
2. **加载不跳转**:点项目只加 tab,不切走当前会话。
3. **会话拉取上限**:沿用主页索引上限(最近 ~100 个根会话),避免一次开几百个 tab。
4. **目录选择单选**(`multiple: false`),对应「新增一个项目+新会话」。
