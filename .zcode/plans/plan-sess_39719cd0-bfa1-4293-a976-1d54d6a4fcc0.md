# 左右布局下内容页顶部支持窗口拖动

## 现状原因
- `tabLayout: "vertical"`（左右布局）时，全宽 36px 标题栏 `<header data-tauri-drag-region>`（`packages/app/src/shell/titlebar/titlebar.tsx:150-174`）被 `hidden` 隐藏（`titlebar.tsx:116,152`）。
- 唯一剩下的拖动区是 macOS 专用的 28px spacer，由 Titlebar Portal 进左侧边栏顶部（`titlebar.tsx:662-668`，`macVerticalTabs()` 门槛）→ 所以只有左侧会话列表顶部能拖。
- 右侧 `<main>`（`packages/app/src/shell/shell.tsx:101-118`）内没有任何 `data-tauri-drag-region`；主页/设置/会话页顶端只是各自的 8px `--shell-top-inset` 间隙 + 圆角卡片，默认不可拖。
- Windows 下左右布局保留标题栏（本身可拖），不受此问题影响。

## 改动（仅 shell.tsx，约 6 行）
1. `<main>` 的 class 加 `relative`。
2. `<main>` 内、页面内容之前，加一条覆盖顶部间隙的拖动条：

```tsx
<Show when={verticalTabs() && platform.platform === "desktop" && platform.os !== "windows"}>
  <div data-tauri-drag-region class="absolute inset-x-0 top-0 z-50 h-[var(--shell-top-inset,8px)]" />
</Show>
```

要点：
- 复用现有机制：`data-tauri-drag-region` 经 `packages/ui/src/styles/base.css:85` 变成 `app-region: drag`；条内没有交互子元素，无需 no-drag 例外。
- 高度 = `--shell-top-inset`（8px），正好是卡片上方的可见缝隙：主页/设置/会话页统一生效，不遮挡任何页面内容，零视觉变化。
- 锚定 `<main>` 而非窗口根：Windows 显示标题栏时不会错位；门槛条件与隐藏标题栏的条件对齐（竖排布局 + 非 Windows 桌面）。
- `z-50` 保证盖在内容之上（这 8px 区域内本无内容；会话页 Review 悬浮钮、粘性标题栏都从 y=8px 以下才开始，不冲突）。

## 不改的
- 三个内容页组件、Titlebar、base.css 全部不动；横向标签布局与 Windows 完全无感知。

## 顺带发现（不在本次范围）
- Linux 竖排布局下标题栏同样被隐藏，但侧边栏 spacer 仅 macOS 渲染 → Linux 左右布局目前整个窗口都没有可拖区域。如需要可另行小改。

## 可选增强（默认不做）
- 会话页粘性标题栏（`SessionTitleHeader`，h-12 行）也可加 `data-tauri-drag-region`，整行像原生标题栏一样可拖（按钮自动豁免 no-drag，代价是标题文字无法选中）。需要的话再加。
